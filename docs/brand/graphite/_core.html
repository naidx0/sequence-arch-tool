Every class this substrate defines, rendered once. Nothing below needs re-deriving and nothing below may be restyled. If a sheet needs a shape that is genuinely absent, name it in the handback — six local inventions are six contradictions.

The rules for writing a sheet, the five inherited laws and the two owner decisions are in the comment at the top of this file. Read them before you write.

00.7

Code and diff

mono · --t-11 · the diff text stays --ink-1

Diff is a background wash and a 2px inset gutter. The foreground text of a diff line is never coloured, in any state — a removed line that renders red is indistinguishable from a failed one.

00.8

The board

Decision 2 — kind without hue

Six kinds and not one hue between them. Kind is carried by an icon, a silhouette, a border treatment and a step in the neutral ramp; every pair of kinds differs in at least three of those four. The invariant: every kind stays distinguishable with all colour removed, at every size the silhouette is drawn, from the radii that actually paint. Prove it against the render, never against the token list — a declared radius is scaled by f = min(side / sum of that side's radii) and can be discarded entirely. Hue on a node is reserved for what the node is DOING.

Six silhouettes, no labels, no hue — and still six kinds. Each swatch is half a card, at card aspect, because that is the smallest size at which all six outlines still separate. Here the tab is already 6px, the chamfer 8px and the cylinder arcs 7px — at the floor, not above it. Below this size they go under and the icon takes over as the carrier. Do not read this row as a claim that the outlines survive further out. Border weight does not survive a 1x display at all, where 1.5px snaps to 1px: it reinforces, it never carries.

00.9

Icons

70 symbols · one 1.5px stroke · no emoji

Colour is inherited, so the same glyph sits in a rail at --ink-3, on a tool row at --fits and inside the send button at --accent-on-solid. Size with .i (16px, the default), .i-12, .i-14, .i-18, .i-20 — the stroke does not scale with the box. Give an icon-only control an aria-label.

Handback note. Six of the twelve exist because Decision 2 makes the icon the primary carrier of node kind. A kind without its own glyph pushes the difference back onto hue, which is the defect this rebuild exists to remove. Datastore deliberately gets no new drawing: ic-database already means "a database", and a second drawing for one meaning is the other half of the icon-reuse defect.
