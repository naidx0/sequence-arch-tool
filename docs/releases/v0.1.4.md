# Sequence 0.1.4

## Highlights

- Sign in once during setup. The prompts that repeated before now ask once.
- Workspaces are a tree: folders, with chats under each. New chat opens in the workspace you are in.
- The whiteboard works like the architecture board. Select is the default, Space pans, and letter keys switch tools.
- Edit from here: rewrite an earlier message, and the agent forgets what came after it. Undo lasts until your next send.
- A restart no longer loses a turn. An interrupted turn shows Continue.
- Claude sets itself up the first time you use it. There is no separate install step.
- Refine notes: the app can propose a short note for your project. You accept or dismiss it. Off by default.

## New

- Claude setup: the app downloads its bridge the first time it is needed. Proxies work, and failures say why.
- Restart and continue for turns cut off by a quit. Queued prompts come back held, with Resume.
- Import old Claude Code and Codex chats from the Workspaces header. Importing the same chat twice opens the same chat.
- Several agents at once: tick two or more agents and Send to N. Each gets its own chat and worktree. Compare, merge one, or discard the rest.
- Open a pull request from a worktree chat. The app writes the title and body, commits, pushes, and opens the PR with `gh`. Files that look like secrets are held back and listed.
- Dropped requests are named. When a long message has several requests and the agent skips some, the chat says so and offers Ask again. Off by default. Turn it on in Settings, Agents.
- Drawings in chat. svg and html blocks from the agent draw inline in a sandboxed frame. They are saved under `.sequence/drawings`, and a later block with the same id adds a version.
- Charts from numbers: twelve built-in components (line with forecast, bar, kpi, sparkline, histogram, donut, flow, sequence, load path, timeline, capacity forecast, dashboard). The agent draws them from a spec.
- Refine notes: a quiet card in the chat offers Accept or Dismiss for a proposed note. Accept adds one line to `.sequence/memory/NOTES.md`. Undo removes that line. Nothing is written without an Accept.
- find_files: a read-only tool for agents. It returns the files a question is about, ranked, with a one-line reason for each.
- Files preview: Markdown opens in Preview, Edit, or Diff. Dividers between panes can be dragged.
- Terminal: rebuilt with a one-line prompt that shows the folder, plus keys, history, paste, and a toolbar.

## Changed

- Settings: every pane scrolls and returns to the top when you switch. API key fields appear only after you choose API key. Theme is a three-way switch. One notifications switch says why it is blocked when it cannot work.
- The reasoning picker is a slider from Faster to Smarter, with a Recommended caption.
- Agents show context and output tokens, and durations such as "1h 05m".
- Switching chats inside the same workspace is faster.
- The architecture board has one view dropdown and no kinds key.
- Compressed windows: the minimum window size is 960 by 640. Tags fold inside panes, and top tabs keep their names.
- Drawing cards show only a title. Actions appear on hover or focus. A card can be resized and keeps its size.
- Charts are drawn at the chat column's width, and no chart is taller than 420 px at the default width.
- Short answers: the built-in instructions that asked for one sentence or to be concise are gone.
- Chat history sent to hosted models is longer. Local models get a share of the window the server runs.
- The terminal loads the first time you open it, so it is blank for a moment that first time.
- The loading spinner is a braille radar in the chat header and status bar.

## Removed or replaced

- The "Install bridge" button for Claude is replaced by the automatic setup above.
- The separate Chats list is replaced by the Workspaces tree.
- The Markdown edit modes are replaced by one edit mode with Preview and Diff.

## Fixed

- Switching chats no longer shows a false authentication error for an old failure.
- A damaged chat file is never read as empty. The last good copy is used, the damaged file is kept beside it, and the chat says so.
- Turns past 200 stay on disk, and the chat shows "N older turns are saved on disk" with a Show older button.
- Saving progress on a long chat is faster, and importing a large history no longer freezes the window.
- Side panel resize is smooth and solid.
- Dragging works without the arrow circle.
- Workspaces you remove stay removed.
- The terminal prompt no longer shows the machine name. The folder path comes first.
- Icons, the spinner, and the whiteboard toolbar line up.

## Known issues

- The installers are not signed. Windows and macOS warn when you open them the first time.
- Onboarding sign-in has not been checked with a real signed-out agent.
- A `--repo` folder outside your home folder drops off the Workspaces list when you switch away from it.
- Switching to a chat in another workspace still reloads the page.
- Lesson mode keeps its lessons at about 150 words.
- Longer answers and refine notes have not been measured on a live model.
- find_files has not been tested with an agent in the loop, and it has not been measured on Windows.
- Six Claude bridge tests are skipped on Windows.

## Downloads

- Windows: `Sequence Setup 0.1.4.exe` (installer) and `Sequence-0.1.4-win.zip` (portable; unzip anywhere and run `Sequence.exe`).

- Linux: an AppImage and a deb (x64).
- `SHASUMS256.txt` lists the SHA-256 of every file.
