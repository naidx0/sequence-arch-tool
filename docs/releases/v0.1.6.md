# Sequence 0.1.6

## Highlights

- Switching a chat to another agent hands it the chat so far, and an agent you switch back to is caught up on what it missed. A one-line note in the chat says so.
- The model picker connects agents in place: Claude Code, Codex and others show Connect or Sign in only when needed, and each agent's models open in a small flyout to the right.
- One workflow per chat. The workflow editor starts as a small pop-up and grows into a large editor, and the chat's agent can edit the workflow for you.
- The window can be dragged again, scrollbars are thin everywhere, and the chat's own scrollbar stays hidden unless you scroll.
- First run can bring your skills from Claude, Codex and Cursor in one click.

## New

- Chat-only view is wider; the reading column stays centred.
- Settings: Interface font (Inter, Geist, IBM Plex Sans, System); Open new surfaces large (the newest surface takes about 75%); rows read label left, control right.
- Updates: What's new collapses to a short highlight with Read more; a failed update offers Ask the agent to help, which drafts a prompt with the error and the links.
- Refresh models reads each provider's own model list (Ollama, OpenAI-compatible, Anthropic).
- Sidebar: pinned chats sit at the top and stay in their project with a pin mark; right-click a project to remove it from the sidebar; drag or Alt+arrows to reorder; counts only past 10 chats with Show all.
- Agents surface keeps its content centred when it is wide or full screen.
- Whiteboard and boards lay out top to bottom by default; the Ask button stays while you move onto it; the ask box looks like the chat box.
- Drawings follow the app's own components: no emoji, theme colours only, kit classes inside html drawings.
- Terminal tools sit in a strip at the bottom and the prompt is drawn in the accent colour; the file editor is smaller, with a gutter sized to its digits and faint lines; the find bar stays whole at every width.
- Markdown preview reads front-matter as rows and draws every mermaid fence.

## Fixed

- The light and dark switch is one quick cross-fade.
- At narrow widths every surface keeps its name and the bar scrolls; the Chat / Workspace switch is centred.
- A model change animates the effort row instead of jumping.
- Settings > Models opens without waiting on a slow local model probe.
- A saved API key is dropped when its profile is pointed at a different address.
