# Sequence 0.1.7

## Highlights

- Each chat keeps its own agent, model and effort. Switching chats, reloading or restarting brings the right model back, and the context circle follows that chat's agent.
- The status bar under the chat box shows the model's real name and icon (for example Opus 4.5) and a context circle: hover it or tab to it for the full breakdown.
- Light mode is creamier, with a softer blue and slightly darker greys. The window background shows a little more.
- Workflow runs read in plain words: the workflow's name, one state word, a short reason and its progress. Technical detail sits behind Details.

## New

- Long model names fade out after about 12 characters, in the chat box and the status bar, with the full name on hover.
- The no-response notice is one calm line with plain buttons; the detail shows on hover.
- Connecting, signing in, installing and updating agents is done with buttons, or a ready prompt for your agent in chat.
- The workflow start form uses plain words and regular fields, and the model list shows full model names.
- The desktop app keeps a short log of window closes, crashes and server restarts (keys and tokens hidden), and reloads a crashed page once.
- Updates also understand four-part versions such as 0.1.7.1.

## Fixed

- Commands typed or sent to the terminal now run.
- A reply from a local model no longer appears above earlier answers.
- A fresh profile no longer starts Codex on a model your sign-in cannot use.
- Picking the same model in two chats now sticks in both.
- Start run stays off until an agent is connected.

## Mac

- Easiest Apple silicon install: paste one prompt into Claude Code or Codex on your Mac and it downloads the latest build, checks the SHA-256, installs Sequence to Applications, clears the quarantine flag on that app only and opens it. The prompt is on the download section of trysequence.app and in `docs/install/mac-agent-prompt.md`.
- Builds are still not notarized with Apple, so a plain double-click ends at "Apple could not verify"; the prompt (or System Settings, Privacy & Security, Open Anyway) gets past it.
