# Sequence 0.1.5

## Highlights

- Codex and other connected agents are always in the model picker. If the model list cannot be read, you get the agent's default model, the reason, and one Retry. Disconnecting and connecting update the picker at once.
- A chat turn keeps running when you reload or open another workspace. Come back and the page picks the turn up where it is, and Stop still works.
- The app can tell you when a new version is out. Settings shows the version and build, checks daily, and installs an update in one click.
- Surfaces are easier to use: tabs and header pills can be clicked, dragged to reorder, and scrolled with the wheel, and panes stop shrinking before they hide their content.
- Ask on the whiteboard is never disabled. It opens on any board.
- Plans and questions from an agent appear as a card you can answer with a click.

## New

- Update in Settings: version and build with a copy button, a daily check against the GitHub release, and one-click install. The installer is checked against the release's SHA-256 list before it runs, and only the installed desktop app offers to run it. Any other copy gets a link to the release page and the reason. Release notes for each version are shown inside the app.
- Decision card: when a finished turn ends by asking, or hands over a plan, the chat shows it as a card. Pick one or more options as chips, then Send. Nothing is sent until you press Send. A plan written in words is read too.
- Background runs: every chat's agent run shows on its rail row, running or finished while you were elsewhere. A chat whose agent is waiting on an approval or a question says "Needs you".
- Several chats at once across workspaces. Three agents in two workspaces can stream together, and switching between them leaves the others running.
- Stop names the turn it stops. A Stop pressed before the server has named the turn waits for the name and then stops that turn.
- Worktrees in the sidebar fold like Skills.
- Whiteboard: the text tool opens a note for typing right away, with the placeholder selected.

## Changed

- Inline drawings fold with one click, the title is centred, and the drawing scales to the chat column with no height cap and no scrollbar. Text is fitted to its box. Flows with more than three steps run top down. A single svg is centred in full screen.
- The agent now gets drawing guidance: vertical first, short labels, a fitted svg, and four worked examples.
- Agent drawings on the whiteboard land readable. Boxes grow to fit their text and push their neighbours, connectors follow, labels sit clear of borders, and notes are wrapped and kept off boxes.
- Whiteboard toolbar: one grid for menu rows, menus stay inside the board, Eraser folds into More under 270 px, Ask has a fixed width, and the icon weights match.
- Narrow panes: board tags fold to one pill when they would not fit, in a pane of 320 px or less, and chat never squeezes a pane below 240 px.
- Splits, chat and pane drags are smooth: sizes update per frame and are saved once when you let go.
- The model chip reads an agent with no named model as its default, such as Codex default.
- Switching workspaces takes the app from cache on the reload, so it is faster.
- A turn the page cannot follow falls back to the saved record. Replays are kept by size (16 MB), not by count, and a page told of a trimmed turn takes the whole saved record at the end.

## Fixed

- A connected Codex or OpenAI agent no longer leaves you with an empty model picker, and reconnecting reads it afresh.
- A reload or opening another workspace no longer stops every running agent.
- Header pills under the window drag region could not be clicked.
- A box pushed by two growing neighbours moved from the wrong place, and its connectors did not follow.
- The updater's write and spawn errors fail the install job with a reason instead of crashing the server, a stalled download fails by itself, and a second install cannot start while one is running.

## Known issues

- Switching to a chat in another workspace still reloads the page (about 0.5 to 0.7 s).
- Updates are checked against the release's SHA-256 list but are not yet signed. Signature checking is built and stays off until the release key is pinned.
- The Electron app is not notarized on macOS. On macOS 14 and earlier, right-click the app and choose Open. On macOS 15 and later, open it once, then go to System Settings, Privacy & Security, and press Open Anyway.
