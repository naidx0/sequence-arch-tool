How the scanner reaches the graph

Three passes, and nothing is inferred between them — every edge that survives into the graph carries the file and span it came from.

  • Walk. src/scan.ts enumerates the tree once, honouring .gitignore, and hands each file to the language probe.
  • Resolve. Imports become candidate edges; unresolved ones are kept as unknown rather than dropped, so the gap is visible instead of silent.
  • Fold. Candidates collapse into services and the graph is emitted with provenance attached to each edge.

The third pass is the only one that can lose information, which is why it is the one with the locking test.
