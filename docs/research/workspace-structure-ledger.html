4 · AI Canvas — file-type bonded output (not freeform stickies)

Round 3 stickies looked bad because the surface had no output contract. AI Canvas is bonded to artifact types the AI chooses via native tools — each renders through a known viewer so output is clean every time.

Tool nameBlock typeWhen AI uses itRendered as
canvas.write_markdownMarkdown (.md)Planning, prose, MADR body, fenced code snippetsTypeset MD viewer — headings, lists, callouts, code fences
canvas.write_mermaidMermaid (.mmd or fenced block)Flowcharts, sequences, dependency graphsNative mermaid renderer — same pipeline as chat diagrams
canvas.write_htmlHTML (.html)Static layouts, comparison grids, annotated screenshotsSandboxed HTML frame — Graphite tokens only
canvas.write_reactReact (.tsx)Animated charts, step-through demos, interactive widgetsMounted component preview — Recharts / motion, bounded
canvas.write_svgSVG (.svg)Precise vector diagrams, icons, annotated paths — when Mermaid is too coarseInline SVG viewer — pan/zoom, no script
Five native writers — closed set. The model may only append canvas blocks through these tools. Human pan/zoom + point-to-ask; human does not hand-edit layout. Opening plan.md or a MADR binds the canvas to that file's thread.

✕ Not on AI Canvas: .seqd (Architecture scan IR), whiteboard strokes, raw JSON/YAML/CSV blocks (use MD code fence or HTML table), binary images (embed in MD/HTML). PDF is export-only, not a block type.
