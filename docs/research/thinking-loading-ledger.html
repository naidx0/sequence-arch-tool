What must not change

One line per call. Live row uses present progressive (Reading session.ts…). On land it is replaced by past tense (Read session.ts) — never appended. Sheet 12.3 + Decision 7.

Named from the real event. Labels come from the ask stream verb, not generic “Working…”. workRowModel.ts owns the mapping.

Inline in the answer. Rows sit under the left rule inside prose flow — not a detached trail block above the answer.

No hue while running. Motion uses --ink-2/3 and optional accent wash; verdict colours wait until land.

How to combine (if you want a custom mix)

A + braille from C → shimmer row with braille only on reasoning, glyph pulse on reads. Keeps rows at 26px, adds ASCII without density beside every icon.

B without wash on landed rows → wash is live-only; the ::before pot disappears on replace — no ghost animation on history.

D but orbit spinner → swap density for ◐◓◑◒ if density feels too “matrix”. Same layout, softer motion.

E minus agent bar → if you like the density+shimmer+wash stack, drop AgentRunBar first — that single card causes most of the duplication.

Reduced motion → all specimens fall back to static label + static glyph at prefers-reduced-motion (already wired in product CSS).
