Method, honestly

Fifty fixed instances from SWE-bench Verified (django + sphinx), each solved cold in its official Docker image by the Sequence CLI under Full permission, patches collected by git diff, judged by the official swebench evaluator running each repository's own FAIL_TO_PASS / PASS_TO_PASS tests. One model, pinned decoding, one variable per run. Every claim above traces to a preserved official-report-*.json; the harness improvements each carry a locking test in this repository. What we do not claim: full-500 numbers, other-model numbers we have not run, or comparability beyond what the caption states.
